- [x] Nextbridge 브랜드와 프로그램 목록
- [x] 로그인 없는 공통 실행 화면
- [x] 팀코드 기반 결과 저장과 JSON 내려받기
- [x] 개인정보·비밀정보 기본 검사
- [x] 공개 저장소와 비공개 운영 플랫폼의 경계

## 현재 단계

- [x] 세 프로그램을 공개용 이름으로 정리

- [x] 실제 AI가 아닌 기능임을 화면에 안내
- [x] 정상·경계·빈칸 테스트 제공
- [x] 첫 번째 실습에서 공통 결과 JSON 생성
- [ ] 학교 환경에서 직접 열기와 로컬 서버 실행 확인
- [ ] 새로운 강사가 안내만 보고 실습을 진행할 수 있는지 확인
- [ ] 학생 화면의 문구와 표 크기 점검
