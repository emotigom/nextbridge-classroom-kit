# 공개 저장소의 안전 경계

이 저장소는 학교와 강사가 확인할 수 있는 **공개 자료 자리**입니다.

## 공개해도 되는 것

- 실제 사람에게서 만들지 않은 합성데이터
- 공개가 확정된 수업 자료
- 로그인 없이 실행되는 예시
- 팀코드 기반의 간단한 결과 형식
- 강사와 학교 IT 담당자를 위한 안내

## 공개하면 안 되는 것

- 실제 학생·학교·강사 정보
- 실제 참여코드와 수업 세션
- 학생 제출물 원본
- API 키, 서비스 롤 키, PAT
- Supabase·R2·KV·Durable Objects 운영 설정
- 비공개 `gom-clean` 소스코드와 감사 로그

## 연결 원칙

- 공개 저장소가 비공개 저장소를 submodule이나 package로 읽지 않습니다.
- 공개 GitHub Actions에서 비공개 저장소를 checkout하지 않습니다.
- 브라우저에서 민감한 데이터베이스에 직접 쓰지 않습니다.
- `gom-clean` 연동은 별도의 HTTPS 계약을 검토하기 전까지 끕니다.
- 공개 클라이언트는 변조될 수 있다고 가정합니다.

## 현재 상태

현재 루트에는 외부 전송 기능이나 실제 수업 운영 기능이 없습니다. 이전에 만든 선택 기능은 Git 이력에 보관되어 있으며, 다시 사용할 때 이 경계를 먼저 확인합니다.
