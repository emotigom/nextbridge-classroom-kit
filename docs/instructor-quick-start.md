# 강사용 3분 시작 안내

이 안내는 학교망이나 외부 서비스 상태와 관계없이 독립 실행 수업을 시작하는 최소 절차입니다.

## 0~1분 · 실행 확인

Node.js 20 이상이 설치된 기기에서 저장소 루트로 이동한 뒤 실행합니다.

```bash
npm run check
npm run dev
```

터미널에 표시된 `http://127.0.0.1:8080/` 주소를 같은 기기의 브라우저에서 엽니다. HTML 파일을 더블클릭해 `file://` 주소로 열지 않습니다.

## 1~2분 · 학생 경로 확인

1. 세 프로그램 카드가 모두 보이는지 확인합니다.
2. `gom-clean 연결 꺼짐` 표시를 확인합니다.
3. 결과카드에서 저장, 저장본 불러오기, JSON 내려받기 버튼을 확인합니다.
4. 실제 사업명이 확정되기 전에는 `program-01~03` 자리를 그대로 사용합니다.

## 2~3분 · 학생에게 말할 문장

> 오늘은 팀마다 실명 대신 팀코드만 사용하겠습니다. 결과카드에는 이름, 학번, 학교명, 연락처를 적지 않습니다. 마지막에는 우리가 만든 결과, 확인한 근거, 다음에 바꿀 한 가지를 남겨볼까요?

팀당 한 기기와 한 브라우저를 기본으로 사용합니다. 브라우저 저장본은 다른 기기나 다른 브라우저로 자동 이동하지 않습니다.

## 수업 종료 전

1. 팀이 결과카드를 브라우저에 저장합니다.
2. 같은 팀코드로 저장본이 다시 불러와지는지 확인합니다.
3. 필요한 경우에만 JSON을 내려받습니다.
4. JSON을 수합할 때도 실제 학생·학교 정보가 없는지 강사가 다시 확인합니다.

이 단계에서는 `gom-clean` 제출을 시도하지 않습니다. 공개 데모는 외부 API를 호출하지 않으며, 수업의 핵심 활동은 독립 실행으로 끝나야 합니다.
