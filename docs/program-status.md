# 프로그램 안내

이 문서는 공개 저장소에서 각 프로그램이 어느 정도 준비되어 있는지만 간단히 보여줍니다.

공식 사업명, 학교명, 일정, 정확한 대상, 내부 문서 버전은 이곳에서 관리하지 않습니다. 수업 자료는 계속 바뀔 수 있으므로 공개용 이름과 현재 사용할 수 있는 기능만 기록합니다.

## program-01 · 학교 AI 수업

현재 사용할 수 있는 것:

- 로그인 없는 기준 비교 실습
- 합성 사례
- 팀 결과 JSON 저장
- 강사용 실행·복구 안내

아직 연결하지 않은 것:

- 전체 교안
- 발표자료
- 학교별 운영안

첫 번째 실습은 실제 AI 모델이 아니라 가중합 규칙을 살펴보는 수업용 시뮬레이터입니다.

## program-02 · 전환기 AI·SW 수업

현재는 프로그램 자리와 기본 보안 규칙만 준비되어 있습니다.

세부 수업 자료, 활동, 도구는 준비되는 순서대로 연결합니다.

## program-03 · 교육 도구 워크숍

현재는 프로그램 자리와 기본 결과 형식만 준비되어 있습니다.

공개할 수 있는 예시와 실행 자료가 정리되면 필요한 범위만 연결합니다.

## 자료 상태 표시

- `not-started`: 아직 공개 자료가 없음
- `pending-review`: 자료는 있으나 공개 여부를 확인 중
- `published`: 현재 사용할 수 있는 공개 파일이 연결됨

## 자료를 연결할 때 확인할 것

1. 실제 학생·학교·강사 정보가 없는지 봅니다.
2. 내부 링크와 비밀정보를 제거합니다.
3. 실제 사람이 아닌 합성데이터만 사용합니다.
4. 로그인 없이 핵심 활동을 할 수 있는지 확인합니다.
5. 실제 AI가 아닌 기능을 AI라고 설명하지 않습니다.
6. 네트워크가 끊겨도 수업을 이어갈 수 있는지 확인합니다.
7. 강사가 쉽게 복구할 수 있는 안내를 함께 둡니다.
8. 마지막에 `npm run check`를 실행합니다.
