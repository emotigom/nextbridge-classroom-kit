# 프로그램 공개 상태

이 문서는 세 사업의 **공개 저장소 반영 상태**를 한곳에서 설명합니다.

- 확인된 사실만 기록합니다.
- 비공개 Notion, 내부 저장소, 운영용 파일 주소는 공개하지 않습니다.
- 미확정 정보는 추측하지 않고 `unconfirmed` 또는 `partial`로 남깁니다.
- 교안·실습도구는 권리와 공개 범위를 확인한 뒤 상대경로로 연결합니다.

## 상태 값

### 운영정보 `delivery.status`

- `unconfirmed`: 학교급·시간·팀구성 등 운영정보가 아직 없음
- `partial`: 일부 정보만 확인됨
- `confirmed`: 필수 운영정보가 모두 확정됨

### 공개자료 `resources.status`

- `not-started`: 공개 자료 준비 전
- `pending-review`: 자료는 준비 중이지만 공개 범위·라이선스 검토가 남음
- `published`: 승인된 파일이 이 저장소의 상대경로로 연결됨

## program-01

**사업명:** 2026 찾아가는 AI교육 지원 프로그램

확인된 내용:

- 고등학교 1–3학년 대상
- 4차시×50분, 총 200분
- 현재 준비 중인 첫 교안은 `AI 공정성 감사관`
- 로그인 없는 실행 도구와 합성데이터를 전제로 준비

아직 확정하지 않은 내용:

- 팀당 인원
- 개인·팀별 기기 운영 방식
- 교안·HTML·학생 데이터의 공개 저장소 포함 범위
- 코드와 별도로 적용할 콘텐츠 라이선스

현재 `resources.status`는 `pending-review`입니다. 공개 승인 전에는 내부 파일 주소나 사본을 manifest에 넣지 않습니다.

## program-02

**사업명:** 2026 중등 학교급 전환기 찾아가는 AI·SW 프로그램

확인된 내용:

- 중학교 3학년과 고등학교 3학년 대상
- 학교급 전환기를 앞둔 학생을 위한 찾아가는 AI·SW 프로그램

아직 확정하지 않은 내용:

- 수업 차시와 전체 시간
- 중3·고3 공통 또는 구분 운영 여부
- 학생 활동, 사용 도구, 산출물
- 팀 구성과 기기 운영 방식
- 공개할 교안과 실습 파일

현재 `resources.status`는 `not-started`입니다.

## program-03

**사업명:** 2026 경기 성취도평가 표준화 평가도구 개발 합숙 워크숍

확인된 내용:

- 3일 합숙 워크숍
- 평가도구 개발을 지원하는 사업

아직 확정하지 않은 내용:

- 공개 Classroom Kit에서 제공할 실행 자료
- 대상 사용자와 팀 구성
- 결과카드의 사업별 추가 필드
- 공개 가능한 예시와 콘텐츠 라이선스

현재 `resources.status`는 `not-started`입니다.

## 첫 공개자료를 연결하기 전 검사

1. 공개 권한과 콘텐츠 라이선스를 확인합니다.
2. 실제 학교·학생·강사 데이터와 내부 링크를 제거합니다.
3. 실제 사람에게서 만들지 않은 합성데이터만 남깁니다.
4. 학생 화면이 로그인 없이 핵심 활동을 완수하는지 확인합니다.
5. 네트워크가 끊겨도 수업 핵심 성취가 유지되는지 확인합니다.
6. 강사가 오류를 3분 안에 복구할 수 있는지 확인합니다.
7. manifest의 `resources`를 상대경로로 연결합니다.
8. `npm run check`와 학교 환경 리허설을 통과합니다.
