# 프로그램 공개 상태

이 문서는 세 사업의 **공개 저장소 반영 상태**를 한곳에서 설명합니다.

- 확인된 사실만 기록합니다.
- 비공개 Notion, 내부 저장소, 운영용 파일 주소는 공개하지 않습니다.
- 미확정 정보는 추측하지 않고 `unconfirmed` 또는 `partial`로 남깁니다.
- 공개 자료는 새로 작성한 코드·합성데이터이거나, 권리와 공개 범위를 확인한 파일만 상대경로로 연결합니다.

## 상태 값

### 운영정보 `delivery.status`

- `unconfirmed`: 학교급·시간·팀구성 등 운영정보가 아직 없음
- `partial`: 일부 정보만 확인됨
- `confirmed`: 필수 운영정보가 모두 확정됨

### 공개자료 `resources.status`

- `not-started`: 공개 자료 준비 전
- `pending-review`: 자료는 준비 중이지만 공개 범위·라이선스 검토가 남음
- `published`: 승인된 파일이 이 저장소의 상대경로로 연결됨

## program-01

**사업명:** 2026 찾아가는 AI교육 지원 프로그램

확인된 내용:

- 고등학교 1–3학년 대상
- 4차시×50분, 총 200분
- 첫 교안 주제는 `AI 공정성 감사관`
- 로그인 없는 공개 starter와 새 합성데이터를 사용

현재 공개된 자료:

- `tool/index.html`: 학생이 여는 단일 실습 화면
- `tool/data.js`, `tool/engine.js`: 합성 사례와 가중합 계산·정상·경계·빈칸 테스트
- `tool/result-card.js`, `tool/core.js`: 결과카드 검사와 공개 API
- `tool/app-*.js`, `tool/styles.css`: 브라우저 화면·상태 저장·내보내기
- `instructor-guide.md`: 기술 실행·정상 결과·복구 안내
- 공통 결과카드 1.1 JSON 내려받기

공개 starter는 **실제 AI 모델이 아닌 가중합 규칙 시뮬레이터**입니다. 실제 사람에게서 만들지 않은 `S01~S12` 합성 사례만 포함하며, 네트워크 요청을 하지 않습니다.

아직 공개하지 않은 내용:

- 전체 4차시 교안 원문과 PPTX
- 내부에서 준비 중인 기존 HTML·문서·CSV 사본
- 팀당 인원과 개인·팀별 기기 운영 방식
- 코드와 별도로 적용할 교안 콘텐츠 라이선스

따라서 `resources.status`는 `published`이지만 `lessonMaterial`은 `null`입니다. 공개된 것은 새로 작성한 실행 starter와 기술 안내이며, 전체 교안 공개를 뜻하지 않습니다.

## program-02

**사업명:** 2026 중등 학교급 전환기 찾아가는 AI·SW 프로그램

확인된 내용:

- 중학교 3학년과 고등학교 3학년 대상
- 학교급 전환기를 앞둔 학생을 위한 찾아가는 AI·SW 프로그램

아직 확정하지 않은 내용:

- 수업 차시와 전체 시간
- 중3·고3 공통 또는 구분 운영 여부
- 학생 활동, 사용 도구, 산출물
- 팀 구성과 기기 운영 방식
- 공개할 교안과 실습 파일

현재 `resources.status`는 `not-started`입니다.

## program-03

**사업명:** 2026 경기 성취도평가 표준화 평가도구 개발 합숙 워크숍

확인된 내용:

- 3일 합숙 워크숍
- 평가도구 개발을 지원하는 사업

아직 확정하지 않은 내용:

- 공개 Classroom Kit에서 제공할 실행 자료
- 대상 사용자와 팀 구성
- 결과카드의 사업별 추가 필드
- 공개 가능한 예시와 콘텐츠 라이선스

현재 `resources.status`는 `not-started`입니다.

## 공개자료를 연결할 때 검사

1. 공개 권한과 콘텐츠 라이선스를 확인합니다.
2. 실제 학교·학생·강사 데이터와 내부 링크를 제거합니다.
3. 실제 사람에게서 만들지 않은 합성데이터만 남깁니다.
4. 학생 화면이 로그인 없이 핵심 활동을 완수하는지 확인합니다.
5. 실제 AI가 아닌 계산 기능을 AI라고 과장하지 않습니다.
6. 네트워크가 끊겨도 수업 핵심 성취가 유지되는지 확인합니다.
7. 강사가 오류를 3분 안에 복구할 수 있는지 확인합니다.
8. manifest의 `resources`를 안전한 상대경로로 연결합니다.
9. `npm run check`와 학교 환경 리허설을 통과합니다.
