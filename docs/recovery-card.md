# 오류 복구 카드

수업 중에는 원인 분석보다 학생 활동을 계속하게 하는 복구 순서를 우선합니다.

## 프로그램 카드가 보이지 않을 때

1. 주소가 `file://`로 시작하는지 확인합니다.
2. 파일을 직접 열었다면 창을 닫고 저장소 루트에서 `npm run dev`를 실행합니다.
3. 터미널에 표시된 로컬 주소를 다시 엽니다.
4. 새로고침 후에도 보이지 않으면 다른 포트로 실행합니다.

macOS·Linux:

```bash
PORT=8081 npm run dev
```

Windows PowerShell:

```powershell
$env:PORT=8081
npm run dev
```

## 저장본을 찾지 못할 때

1. 저장할 때 사용한 것과 같은 기기, 같은 브라우저, 같은 브라우저 프로필인지 확인합니다.
2. 프로그램과 팀코드를 정확히 선택합니다.
3. 팀코드는 대문자로 입력한 뒤 `저장본 불러오기`를 누릅니다.
4. 다른 기기에서 계속해야 한다면 미리 내려받은 JSON을 보관하고, 새 결과카드는 새 기기에서 다시 작성합니다.

현재 공개 데모는 JSON 가져오기를 지원하지 않습니다. 검증하지 않은 파일을 자동으로 불러오는 기능보다 수업 중 안전한 재작성을 우선합니다.

## 저장이 되지 않을 때

1. 팀코드에 한글, 공백, 특수문자가 없는지 확인합니다.
2. 결과, 근거, 다음 개선을 모두 입력합니다.
3. AI를 사용했다고 선택했다면 실제 사용 범위를 적습니다.
4. 자동 개인정보 검사 메시지가 나오면 해당 내용을 지우고 다시 저장합니다.
5. 브라우저 저장소가 차단된 환경이라면 내용을 복사해 안전한 임시 문서에 보관하고, 강사 기기에서 다시 작성합니다.

## 개인정보나 비밀정보를 잘못 적었을 때

1. JSON을 내려받거나 공유하지 않습니다.
2. 해당 프로그램과 팀코드를 선택하고 `저장본 삭제`를 누릅니다.
3. 이미 내려받은 파일이 있다면 기기에서 삭제합니다.
4. 직접식별정보를 제거한 뒤 새 결과카드를 작성합니다.
5. 실제 운영 시스템으로 전송된 경우에는 수업 운영 책임자에게 즉시 알립니다.

## 인터넷이나 외부 서비스가 끊겼을 때

독립 실행 화면이 이미 열려 있다면 그대로 수업을 진행합니다. `gom-clean`, Supabase 또는 다른 외부 서비스 복구를 기다리지 않습니다. 핵심 성취는 브라우저 저장과 JSON 내려받기로 끝낼 수 있어야 합니다.

## 중단해야 하는 경우

실제 학생 데이터, 학교 내부자료, 계정 비밀번호, 참여코드, API 키가 입력되었거나 화면에 노출되었다면 해당 팀의 저장과 공유를 중단합니다. 값을 삭제한 뒤 강사에게 알리고, 안전한 합성데이터로 다시 시작합니다.
