# Nextbridge Classroom Kit

학교와 강사가 **로그인 없이 수업을 시작하고**, 팀 결과를 안전하게 남길 수 있도록 만든 공개형 수업 실행 키트입니다.

> 이 저장소에는 내부 사업명, 학교명, 일정, 참여자 정보처럼 운영에만 필요한 내용은 적지 않습니다.  
> 수업 자료는 계속 다듬어질 수 있으므로, 공개 화면에는 알아보기 쉬운 이름과 현재 사용할 수 있는 기능만 표시합니다.

## 빠르게 실행하기

Node.js 20 이상에서 다음 명령을 실행합니다. 별도 패키지 설치는 필요하지 않습니다.

```bash
npm run check
npm run dev
```

브라우저에서 터미널에 표시되는 로컬 주소를 엽니다.

첫 번째 실습만 확인할 때는 다음 파일을 직접 열어도 됩니다.

```text
programs/program-01/tool/index.html
```

`tool` 폴더 안의 파일은 모두 함께 있어야 합니다.

## 현재 구성

`program-01~03`은 저장소에서 사용하는 기술용 ID입니다. 화면에는 공식 사업명 대신 공개용 이름만 표시합니다.

| ID | 공개용 이름 | 현재 상태 |
|---|---|---|
| `program-01` | 학교 AI 수업 | 로그인 없는 기준 비교 실습 사용 가능 |
| `program-02` | 전환기 AI·SW 수업 | 자료 준비 중 |
| `program-03` | 교육 도구 워크숍 | 자료 준비 중 |

세부 대상, 일정, 차시, 학교별 운영 방식은 공개 저장소에서 관리하지 않습니다.

## 첫 번째 실습에서 할 수 있는 일

`program-01`에는 **기준 바꾸기 실습**이 연결되어 있습니다.

- 준비된 기준을 비교합니다.
- 가중치와 기준 점수를 바꿉니다.
- 경계값과 빈칸을 사람이 다시 확인하도록 설정합니다.
- 정상·경계·빈칸 사례를 따로 시험합니다.
- 팀 결과와 다음 개선을 JSON 파일로 저장합니다.

이 도구는 실제 AI 모델이 아닙니다. 입력값을 가중합하는 수업용 규칙 시뮬레이터이며, 실제 사람에게서 만들지 않은 합성 사례만 사용합니다.

## 수업 자료 안내

교안과 실습 자료는 수업 준비 과정에서 조금씩 바뀔 수 있습니다.

- README에는 특정 교안 파일명이나 세부 버전을 길게 적지 않습니다.
- 현재 사용할 수 있는 파일만 프로그램 카드에 연결합니다.
- 전체 교안이나 발표자료는 공개 범위가 정리된 뒤 추가합니다.
- 파일이 바뀌어도 `programs/<program-id>/manifest.json`의 연결 경로를 기준으로 확인합니다.

## 결과 저장

공통 결과에는 다음 정도만 남깁니다.

- 프로그램 ID
- 팀코드
- 팀이 만든 결과
- 확인한 근거
- 다음 개선
- AI 사용 여부
- 개인정보 확인

결과는 기본적으로 현재 브라우저에만 저장되며 JSON 파일로 내려받을 수 있습니다.

## 공개 저장소와 비공개 운영 플랫폼

### 이 공개 저장소

- 로그인 없는 수업 실행
- 합성데이터와 예시
- 팀코드 기반 결과 저장
- 강사와 학교 IT 담당자를 위한 안내
- 공개 가능한 연동 규격

### 비공개 `gom-clean`

- 교사 인증
- 실제 수업과 세션 운영
- 학생 결과물 수합
- 학교 결과 리포트
- 서버 키와 운영 설정

공개 저장소는 비공개 저장소를 직접 읽지 않으며, 현재 `gom-clean` 연동은 꺼져 있습니다.

## 안전 원칙

- 실명, 학번, 학교명, 연락처를 입력하지 않습니다.
- 실제 학생이나 학교 데이터를 예시로 사용하지 않습니다.
- 학생은 팀코드만 사용합니다.
- 실제 AI가 아닌 기능을 AI라고 과장하지 않습니다.
- 네트워크가 끊겨도 핵심 활동을 계속할 수 있게 합니다.
- 공개 클라이언트는 변조될 수 있다고 가정합니다.

## 저장소 구조

```text
.
├── demo/                         # 공통 시작 화면
├── programs/
│   ├── catalog.json             # 프로그램 목록
│   ├── program-01/              # 첫 번째 실습과 강사 안내
│   ├── program-02/              # 준비 중
│   └── program-03/              # 준비 중
├── schemas/                     # 프로그램과 결과 형식
├── src/                         # 공통 저장·검증 기능
├── docs/                        # 운영·보안·복구 안내
└── scripts/                     # 실행과 자동 검사
```
