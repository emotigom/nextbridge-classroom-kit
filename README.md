# Nextbridge Classroom Kit

공개 가능한 수업 자료를 가볍게 정리해 두는 저장소입니다.

지금은 기능을 많이 넣기보다 **세 프로그램의 자리, 기본 안내, 보안 경계**만 유지합니다. 이전에 만든 결과카드·독립 실행 데모·기준 비교 실습·JSON Schema는 삭제하지 않고 Git 이력에 보관했습니다.

## 현재 남겨둔 것

- `program-01~03` 자료 자리
- 간단한 공개용 시작 화면
- 로컬 미리보기
- 기본 구조와 비밀정보 검사
- 공개 저장소와 비공개 `gom-clean`의 경계

세부 사업명, 학교명, 일정, 교안 버전은 공개 저장소에서 관리하지 않습니다.

## 실행

Node.js 20 이상에서 실행합니다. 별도 패키지 설치는 필요하지 않습니다.

```bash
npm run check
npm run dev
```

`npm run dev`가 표시한 로컬 주소를 브라우저에서 열면 현재 프로그램 자리만 간단히 확인할 수 있습니다.

## 프로그램 자리

| ID | 공개용 이름 | 상태 |
|---|---|---|
| `program-01` | 학교 AI 수업 | 자료를 연결할 자리 |
| `program-02` | 전환기 AI·SW 수업 | 자료를 연결할 자리 |
| `program-03` | 교육 도구 워크숍 | 자료를 연결할 자리 |

현재는 특정 교안이나 실습도구를 기본 기능으로 연결하지 않습니다. 실제로 필요한 자료가 정해졌을 때 해당 프로그램 폴더에 추가하면 됩니다.

## 보관한 기능

이전에 만든 기능은 다음 커밋에 그대로 남아 있습니다.

```text
92b4603d7a904b8fec43bc330d9a704dbc6d40ef
```

보관된 내용:

- 공통 결과카드와 브라우저 저장
- 독립 실행 데모
- 기준 비교 실습도구
- 프로그램·결과 JSON Schema
- 강사 시작·복구 문서
- `gom-clean` 연동 계약 초안
- 단위 테스트와 smoke test

필요한 기능만 다시 꺼내는 방법은 [`archive/README.md`](archive/README.md)에 적어두었습니다.

## 저장소 구조

```text
.
├── programs/                    # 세 프로그램의 빈 자리와 간단한 설명
├── config/brand.json            # Nextbridge 브랜드 표기
├── docs/security-boundary.md    # 공개·비공개 경계
├── archive/README.md            # 이전 기능을 다시 꺼내는 방법
├── scripts/serve.mjs            # 로컬 미리보기
├── scripts/validate.mjs         # 최소 구조·보안 검사
└── index.html                   # 간단한 시작 화면
```

## 안전 원칙

- 실제 학생·학교·강사 데이터를 넣지 않습니다.
- 학생을 구분해야 할 때는 실명 대신 팀코드를 사용합니다.
- API 키, 서비스 롤 키, PAT, 실제 참여코드를 넣지 않습니다.
- 공개 저장소가 비공개 `gom-clean`을 직접 읽지 않습니다.
- 실제 AI가 아닌 기능을 AI라고 과장하지 않습니다.
- 외부 서비스가 없어도 핵심 수업을 진행할 수 있게 합니다.
