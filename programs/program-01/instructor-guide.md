# 기준 바꾸기 실습 · 강사 안내

이 문서는 첫 번째 공개 실습을 쉽게 실행하기 위한 안내입니다. 전체 교안이나 차시별 대본을 대신하지 않습니다.

## 수업 전 확인

### 파일을 직접 여는 경우

1. `tool` 폴더 안의 `index.html`을 엽니다.
2. 화면 상단에 **실제 AI 모델이 아니라는 안내**가 보이는지 확인합니다.
3. 준비된 기준 버튼을 눌렀을 때 표가 달라지는지 확인합니다.
4. 인터넷을 끈 상태에서도 가중치 변경과 테스트가 작동하는지 확인합니다.

### 저장소에서 실행하는 경우

```bash
npm run check
npm run dev
```

공통 시작 화면에서 첫 번째 프로그램의 **실습 도구 열기**를 누릅니다.

## 정상 동작 확인

정확한 사례 목록을 외우지 않아도 됩니다. 다음 네 가지만 확인하면 됩니다.

- 준비된 기준을 바꾸면 일부 결과가 달라집니다.
- 경계 테스트는 설정에 따라 사람 확인으로 표시됩니다.
- 빈칸 테스트는 사람 확인 규칙을 켰을 때 자동 확정되지 않습니다.
- 세 테스트를 마치면 팀 결과 JSON을 내려받을 수 있습니다.

## 학생에게 먼저 말할 문장

> 이 화면은 사람을 평가하는 실제 AI가 아닙니다. 우리가 정한 기준을 계산하는 모의 도구입니다. 오늘은 점수를 높이는 것이 아니라, 기준을 바꾸었을 때 결과가 어떻게 달라지는지 확인해볼까요?

## 권장 흐름

1. 처음 기준을 열고 결과를 살펴봅니다.
2. 다른 기준으로 바꾸어 달라진 사례를 찾습니다.
3. 경계와 빈칸 테스트를 실행합니다.
4. 가중치 하나만 바꾸고 결과 차이를 설명합니다.
5. 팀코드와 다음 개선을 적고 JSON을 내려받습니다.

## 빠른 복구

- 화면이 깨지면 `tool` 폴더의 파일이 모두 함께 있는지 확인합니다.
- 이전 팀 기록이 남아 있으면 **전체 초기화**를 누릅니다.
- 브라우저 저장이 막혀도 실험은 계속할 수 있습니다.
- 수업 종료 전 필요한 팀만 JSON을 내려받습니다.
- 네트워크 오류가 나면 외부 제출을 반복하지 않습니다. 이 실습은 원래 네트워크를 사용하지 않습니다.

## 개인정보와 표현

- 합성 사례 ID만 사용합니다.
- 실제 학생, 학교, 지역 정보를 사례에 넣지 않습니다.
- 계산 결과를 사람의 능력이나 가치로 설명하지 않습니다.
- `우선안내`, `일반안내`, `사람 확인` 같은 운영 표현을 사용합니다.
