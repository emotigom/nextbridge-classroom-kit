# AI 공정성 감사관 · 강사 실행 안내

이 문서는 공개된 로그인 없는 실습 도구의 기술 운영 안내입니다. 전체 4차시 교안 원문을 대신하지 않습니다.

## 수업 전 3분 확인

### 파일을 직접 여는 경우

1. `tool` 폴더 안의 `index.html`을 더블클릭합니다.
2. 화면 상단에 `실제 AI 모델이 아닙니다`라는 안내가 보이는지 확인합니다.
3. 인터넷을 끈 상태에서도 기준 버튼·표·테스트가 작동하는지 확인합니다.

### 저장소에서 실행하는 경우

```bash
npm run check
npm run dev
```

브라우저에서 프로그램 카드의 **실습 도구 열기**를 누릅니다.

## 정상 동작 기준

### v0 과거 기록 중심

- 우선안내: `S02 · S05 · S09 · S10 · S12`
- 사람 확인: 없음

과거 완료율 `C`가 높은 일부 저필요 사례가 우선안내되고, 현재 필요가 큰 일부 사례는 빠집니다.

### v1 현재 필요 중심

- 우선안내: `S01 · S03 · S06 · S07 · S09 · S12`
- 사람 확인: `S04`

### v2 사람 확인 포함

- 우선안내 계산: `S01 · S03 · S06 · S07 · S09 · S12`
- 사람 확인: `S04 · S11`
- 빈칸 테스트의 `S07`: 사람 확인

## 학생에게 먼저 말할 문장

> 이 화면은 사람을 평가하는 실제 AI가 아닙니다. 우리가 정한 가중치를 계산하는 모의 규칙입니다. 오늘의 목표는 점수를 높이는 것이 아니라, 어떤 기준이 누구에게 불리해지는지 증거로 확인하는 것입니다.

## 권장 활동 흐름

1. v0을 선택하고 우선안내 목록을 기록합니다.
2. v1을 선택해 바뀐 사례 ID를 확인합니다.
3. v2에서 경계·빈칸 테스트를 실행합니다.
4. 한 번에 가중치 하나만 바꾸고 결과 차이를 설명합니다.
5. 팀코드와 다음 개선을 입력한 뒤 결과카드 JSON을 내려받습니다.

## 즉시 복구

- 화면이 깨지면 `tool/` 폴더의 HTML·CSS·JavaScript 파일이 모두 함께 있는지 확인합니다.
- 이전 팀 기록이 남아 있으면 **전체 초기화**를 누릅니다.
- 브라우저 저장이 막혀도 실험은 가능하며, 수업 종료 전에 JSON 내려받기를 사용합니다.
- 네트워크 오류가 나면 외부 제출을 재시도하지 않습니다. 이 도구는 원래 네트워크를 사용하지 않습니다.

## 개인정보·표현 원칙

- 사례는 `S01~S12` 합성 ID만 사용합니다.
- 실제 학생·학교·지역 정보를 사례에 대입하지 않습니다.
- 계산 결과를 사람의 능력이나 가치로 설명하지 않습니다.
- `우선안내`, `일반안내`, `사람 확인`이라는 운영 표현을 사용합니다.
