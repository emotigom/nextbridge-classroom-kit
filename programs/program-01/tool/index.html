NEXTBRIDGE · PROGRAM 01

기준 바꾸기 실습

가중치와 사람 확인 규칙을 바꾸며 결과 차이를 살펴봅니다.

이 도구의 정체

실제 AI 모델이 아닙니다. 다섯 입력을 가중합하는 수업용 규칙 시뮬레이터이며, 모든 사례는 새로 만든 합성데이터입니다.

실명·학교명·학번을 입력하지 않습니다. 팀 식별은 영문 대문자·숫자·하이픈으로 만든 팀코드만 사용합니다. 네트워크 요청은 발생하지 않습니다.

평범한 사례, 기준점수 근처 사례, 빈칸 사례를 각각 실행하고 자동 확정해도 되는지 살펴봅니다.
