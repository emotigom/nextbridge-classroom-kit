3-MINUTE START

  1. npm run check로 기본 검사를 통과합니다.
  2. npm run dev를 실행하고 화면의 로컬 주소를 엽니다.
  3. 팀코드만 정한 뒤, 학생에게 실명이나 학교명을 적지 말라고 안내합니다.
